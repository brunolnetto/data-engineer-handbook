# Homework 2: Fact Data Modeling

## Overview
This homework focuses on fact table modeling and advanced SQL analytics. You will design and implement fact tables, write analytical queries, and practice ETL logic for a movie analytics dataset. The tasks cover a range of fact modeling and query scenarios.

## Structure
- `task_1.sql` to `task_8.sql`: Each file contains a specific modeling or analytics task, including DDL, DML, and analytical queries
- `homework.md`: Assignment description and requirements
- `.gitkeep`: Placeholder for version control
- `homework_2.zip`: Archive of all homework 2 files

## Learning Objectives
- Practice fact table modeling and ETL logic
- Write advanced SQL for analytics and reporting
- Implement window functions, aggregations, and joins
- Apply best practices for scalable analytical data models

## How to Use
1. Review `homework.md` for assignment instructions.
2. Examine each `task_X.sql` file for the corresponding modeling or analytics step.
3. Run the SQL scripts in order on a PostgreSQL-compatible database.
4. Use the provided DDL and queries as reference for fact modeling and analytics.

## Notes
- The SQL files are modular and can be run independently if the required tables exist.
- The tasks are designed to build on each other for a complete analytics workflow.
